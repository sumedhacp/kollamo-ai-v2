# Model Evaluation & Benchmarking — Kollamo.ai

## 1. Evaluation Methodology

All models evaluated in Kollamo.ai are validated against held-out, non-overlapping test partitions.

### Core Metrics Tracked
- **Accuracy**: Overall fraction of correct predictions across all 5 classes (Actual Measured only).
- **Macro Precision**: Unweighted mean of precision per class (penalizes failure on rare classes).
- **Macro Recall**: Unweighted mean of recall per class.
- **Macro F1-Score**: Primary target metric for model selection.
- **Weighted F1-Score**: F1 weighted by support of each class.
- **Per-Class Precision, Recall, and F1**: Detailed breakdown for `positive`, `negative`, `neutral`, `mixed`, and `unsupported`.
- **Confusion Matrix**: Full 5x5 multi-class confusion matrix.
- **Validation Loss**: Multi-class cross-entropy loss computed across validation epochs.

---

## 2. Dedicated Class Evaluation Requirements

### 2.1 Mixed Class Evaluation
The `Mixed` class represents comments exhibiting dual polarity (e.g. praise for acting accompanied by criticism of plot). Because overall accuracy can mask failure on mixed sentiment, evaluation explicitly computes:
- `Mixed Precision`
- `Mixed Recall`
- `Mixed F1-Score`
- Confusion matrix cross-rates (`Mixed` confused as `Positive` vs. `Negative`).

### 2.2 Unsupported Class Evaluation
The `Unsupported` class captures non-sentimental noise, spam, and non-linguistic data. Evaluation must explicitly report:
- `Unsupported Precision`
- `Unsupported Recall`
- `Unsupported F1-Score`
- Rejection fidelity on symbol noise and unprocessable inputs.

---

## 3. Baseline Model Benchmark

To ensure scientific rigor, a classical baseline is established prior to MuRIL deep neural evaluation:

- **Baseline Architecture**: TF-IDF Feature Extraction + Logistic Regression.
- **Tokenizer**: Sublinear term frequency, character & word n-grams `(1, 2)`.
- **Classifier**: Multi-class Logistic Regression with L2 regularization (`C=1.0`).

All MuRIL fine-tuning results are benchmarked against this baseline to quantify neural representations gain on code-mixed Malayalam.

---

## 4. Error Analysis Taxonomy

Evaluation must explicitly test and report model error rates across 8 specific linguistic phenomena:
1. **Slang & Colloquialisms**: Regional Malayalam slang (e.g., `kidilan`, `polichu`, `thara`, `chali`).
2. **Spelling Variations in Manglish**: Transliteration ambiguities (e.g., `adipoli` vs `athi poli` vs `adypoli`).
3. **Code-Mixing Density**: Comments alternating between Malayalam and English syntactical structures.
4. **Sarcasm & Irony**: Subtle positive wording masking negative sentiment.
5. **Negation Flipping**: Clauses featuring negation markers (`alla`, `illa`, `pattoola`).
6. **Emoji Influence**: Comments containing sentiment emojis with or without accompanying text.
7. **Short vs. Long Comments**: Single-word reactions vs. paragraph-length movie critiques.
8. **Discourse Markers**: Comments with `"pakshe"` / `"but"` requiring discrimination between mixed polarity and factual continuation.

---

## 5. Academic Integrity & Transparency (Zero Fabricated Metrics)

- **Target vs. Actual Rule**: Project target accuracy goals are documented strictly as targets. They are **never** reported as current performance unless experimentally measured on the full dataset.
- **Experiment Provenance**: Every metric artifact generated by `ml/scripts/evaluate.py` must include:
  - Dataset commit SHA and partition sizes.
  - Hyperparameters and random seed.
  - Hardware specifications and inference throughput.
  - Timestamp and Git commit SHA.

---

## 6. Measured Baseline Benchmark Results

Empirical results from the initial baseline run (`ml/evaluation/reports/baseline_metrics.json`):
- **Model**: TF-IDF (1, 2 n-grams, sublinear TF) + Logistic Regression (`C=1.0`)
- **Dataset Split**: Stratified 80% Train, 10% Val, 10% Test (Seed 42, Zero Data Leakage verified)
- **Overall Accuracy**: **33.3%** (Actual measured)
- **Macro F1-Score**: **0.3371**
- **Weighted F1-Score**: **0.3381**
- **Per-Class Breakdown**:
  - `positive`: Precision 0.5000, Recall 0.3333, F1 0.4000
  - `negative`: Precision 0.0000, Recall 0.0000, F1 0.0000 (Failed on unseen colloquial criticism)
  - `neutral`: Precision 0.3333, Recall 0.3333, F1 0.3333
  - `mixed`: Precision 0.2500, Recall 0.3333, F1 0.2857
  - `unsupported`: Precision 0.5000, Recall 1.0000, F1 0.6667
- **Diagnostic Linguistic Error Analysis**:
  - Slang & Colloquialisms: 0.0% (Out-of-vocabulary failure)
  - Spelling Variations: 0.0% (Sensitive to exact character n-gram spelling)
  - Sarcasm & Negation: 0.0% (Inverted polarity missed by bag-of-words)

**Empirical Conclusion**:
Classical TF-IDF methods fail on regional slang and code-mixing. This justifies fine-tuning `google/muril-base-cased` to produce the specialized `kollamo-muril-sentiment-5class` classifier.
